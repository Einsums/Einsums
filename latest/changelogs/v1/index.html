v1.1.2 Release#

What’s New#

  • You can now install the Python module where ever you want.

Bug Fixes#

  • Fixed a compilation error with HPTT using AVX512 intrinsics on incompatible systems.

v1.1.1 Release#

What’s New#

  • Batching over collections of tensors has been added to Python.

Bug Fixes#

  • Fixed a consistent issue where the launch parameters in almost all GPU kernels were swapped. The correct order should be <<<grid_specification, block_specification [, managed memory [, stream]]>>>.

  • Fixed a race condition in most of the GPU linear algebra functions.

  • Removed assertions in the device tensor headers and replaced them with if statements.

  • Fixed a bug in the Python in-core dot product contraction where the AB_prefactor was not actually used.

v1.1.0 Release#

What’s New#

  • Views of block and tiled tensors has been made easier.

  • TensorViews can be made from RuntimeTensors and RuntimeTensorViews so that compile-time rank can be assigned to them.

  • Buffer allocators for future projects. These allow users to limit the amount of memory used by Einsums.

  • Tensor permutations where the smallest stride is not 1.

  • The in-core generic algorithm is now much more performant.

  • The dispatching function for einsum is now more modular, so it is hopefully easier to maintain.

  • Einsum calls can now be batched over containers, such as vectors and arrays of tensors.

  • Linear algebra functions are now available in Python.

  • Complex implementations for several linear algebra functions that were previously missing, such as gees.

What’s Removed#

  • sort is no longer a valid alias for permute.

Bug Fixes#

v1.0.4 Release#

What’s New#

  • Indices no longer accepts things that aren’t indices as arguments. This means that a tensor that shadows an index name will throw a more reasonable error, rather than the esoteric mess that it had in the past.

Bug Fixes#

  • GPU tensor contractions now compile properly.

  • BlockTensors with a block of zero size will no longer cause segfaults with an einsum call.

v1.0.3 Release#

Bug Fixes#

  • Fixed how the Python module is linked to hopefully produce smaller binaries.

v1.0.2 Release#

Bug Fixes#

  • Fixed a typo in arange. It was throwing an error when valid inputs were passed.

  • Fixed a synchronization issue in the GPU tensor contractions

  • Fixed a bug in the in-place tensor-scalar operations for Tensor

  • Fixed a typo in truncated_svd that could cause compilation errors

  • Fixed the hip_catch family of functions so they would not construct temporary strings for every call. They now only construct temporary strings on failure.

v1.0.1 Release#

What’s New#

  • Modules can add their own command line arguments

  • More constructors for RuntimeTensors

v1.0.0 Release#

What’s New#

  • Arbitrary tensor views of pointers

  • Python support

  • Option and configuration maps

  • Better exception handling

  • Macros and base classes for common design patterns

  • Much more

What’s Changed#

  • The project has been restructured

  • sort is now permute

  • Several namespaces have been renamed

What’s Removed#

  • Temporarily removed Windows support

Bug Fixes#

  • Improved performance with some tensor contractions

Optimization Passes#

See the pass catalog for what each one matches, what it reports, and where it sits in the default pipeline.

Infrastructure#

  • einsums::compute_graph::OptimizerPass - the base class every pass derives from.

  • einsums::compute_graph::PassManager - ordered pass list; create_default(), create_for(OptLevel), explain().

  • einsums::compute_graph::OptLevel - O0 / O1 / O2.

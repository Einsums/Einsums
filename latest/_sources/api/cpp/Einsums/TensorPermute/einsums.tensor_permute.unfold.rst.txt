einsums::tensor_permute::unfold
===============================

.. note::

.. cpp:namespace:: einsums::tensor_permute

.. cpp:function:: template <typename T> void unfold(std::size_t mode, detail::TensorImpl<T> *C, const detail::TensorImpl<T> &A)

   Write the mode-``mode`` unfolding of ``A`` into ``C``.

   :math:`C(a_{mode}, z) = A(a_0, \ldots, a_{N-1})`, where the column :math:`z` runs over the
   remaining modes in their order with the first varying fastest:
   :math:`z = a_{r_1} + d_{r_1} (a_{r_2} + d_{r_2} (\ldots))`. This is the unfolding of Kolda and
   Bader, and the column order is fixed: it does not depend on either tensor's memory layout.

   It is a permutation that brings ``mode`` to the front, written through a view of ``C`` that splits
   its column axis into the remaining modes, so no reshaped copy is made.

   .. code-block:: text

      tensor_permute::unfold(1, &C, A);  // A is 3 x 4 x 5, C is 4 x 15

   .. versionadded:: 2.0.0

   :throws RankError: when ``C`` is not rank 2, or ``mode`` is not an axis of ``A``.
   :throws DimensionError: when ``C`` is not ``A's`` extent along ``mode`` by the product of the others.

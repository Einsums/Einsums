einsums::tensor_permute::HasTensorImpl
======================================

.. note::

Defined in header ``Einsums/TensorPermute/Permute.hpp``.

.. cpp:namespace:: einsums::tensor_permute

.. cpp:concept:: template <typename T> HasTensorImpl

   A tensor type that exposes the TensorImpl it wraps, as every dense tensor, view and RuntimeTensor does.

   The overloads below take such tensors directly, so callers never reach for ``impl()``, while
   this module still depends on nothing above TensorImpl.

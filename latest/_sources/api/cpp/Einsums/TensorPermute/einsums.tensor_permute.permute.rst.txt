.. cpp:function:: template <bool ConjA = false, typename T> void permute(std::string_view spec, T beta, detail::TensorImpl<T> *C, T alpha, const detail::TensorImpl<T> &A)

   Compute :math:`C = \beta C + \alpha\,\mathrm{permute}(A)`, the axes named by a spec.

   .. code-block:: text

      tensor_permute::permute("kij <- ijk", 0.0, &C, 1.0, A);  // C(k, i, j) = A(i, j, k)

   Empty operands are valid and leave ``C`` as it is.

   .. versionadded:: 2.0.0

   :tparam ConjA: If true, conjugate the elements of ``A`` as they are permuted.
   :tparam T: The element type of both tensors.
   :throws RankError: when a side does not have one letter per axis of its operand, or the two sides do not name the same axes.
   :throws DimensionError: when an axis of ``C`` does not have the extent of the axis of ``A`` it takes.

   Compute :math:`C = \beta C + \alpha\,\mathrm{permute}(A)` on tensors, the axes named by a spec. The same signature as ``compute_graph::permute``.

   .. code-block:: text

      tensor_permute::permute("kij <- ijk", 0.0, &C, 1.0, A);  // C(k, i, j) = A(i, j, k)

   .. versionadded:: 2.0.0

   :throws RankError: when a side does not have one letter per axis of its operand, or the two sides do not name the same axes.
   :throws DimensionError: when an axis of ``C`` does not have the extent of the axis of ``A`` it takes.

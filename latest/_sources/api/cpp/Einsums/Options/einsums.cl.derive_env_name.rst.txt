.. cpp:function:: std::string derive_env_name(std::string_view prefix, std::string_view long_name)

   Derive an environment variable name from a prefix and an option name.

   Separators become underscores, letters are upper-cased, anything else is dropped, and the prefix
   is prepended unless already there. Empty when ``prefix`` is.

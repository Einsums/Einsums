.. cpp:namespace:: einsums::cl

.. cpp:function:: void register_option(ConfigOption<bool> &opt)

   Give a descriptor its command-line, environment, and config presence.

   Derives the config key and environment variable from the name; a boolean also gets its `--no-`
   twin. Registering twice is a no-op; the options live until exit.

   .. versionadded:: 2.0.0

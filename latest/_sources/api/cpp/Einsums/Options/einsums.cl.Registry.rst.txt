.. cpp:namespace:: einsums::cl

.. cpp:class:: Registry

   Process-wide list of every declared option.

   Options add themselves on construction and remove themselves on destruction.

   .. warning::

      Neither the registry nor the option state it points at is
      synchronized. Declare options and call ``parse`` from one thread.

   .. cpp:function:: void set_env_prefix(std::string prefix)

      Turn on automatic environment variable names for every option.

      Options without their own variable derive one (see ``derive_env_name``): with prefix
      `EINSUMS`, `einsums:log:level` reads `EINSUMS_LOG_LEVEL`. An empty prefix disables this.

      :param prefix: The variable-name prefix, without a trailing underscore.

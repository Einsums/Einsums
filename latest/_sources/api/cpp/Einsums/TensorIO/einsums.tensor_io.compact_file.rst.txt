einsums::tensor_io::compact_file

.. note::

.. cpp:namespace:: einsums::tensor_io

.. cpp:function:: void compact_file(std::string path)

   Rewrite ``path`` without the space no entry uses.

   The file is the old one or the compacted one whenever the program stops, and the disk needs room
   for the entries' bytes while this runs. See ``TensorFile::compact``.

   .. versionadded:: 2.0.0

   :throws std::runtime_error: when the file is missing.

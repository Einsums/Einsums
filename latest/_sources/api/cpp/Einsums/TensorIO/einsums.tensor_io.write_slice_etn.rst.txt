.. cpp:function:: template <CoreBasicTensorConcept TensorType> void write_slice_etn(std::string file_path, std::string tensor_name, const Slab &slab, const TensorType *input)

   Write a slab of a tensor to a .etn file, graph-aware.

   During capture, records a DiskWrite node that patches the slab in place (see ``Slab``). The
   entry must already exist, from ``write_etn`` or ``TensorFile::reserve``.

   .. code-block:: text

      Slab slab{{ {0, 4}, {0, 4} }};
      tensor_io::write_slice_etn("scratch.etn", "T", slab, &block);

.. cpp:function:: template <CoreBasicTensorConcept TensorType> void read_etn(std::string file_path, std::string tensor_name, TensorType *output)

   Read a tensor from a .etn file, graph-aware.

   During graph capture, records a DiskRead node. Outside capture, reads immediately.
   Works with IOPrefetch for async overlap when using DataflowExecutor.

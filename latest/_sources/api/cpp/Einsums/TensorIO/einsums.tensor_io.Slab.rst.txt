.. cpp:class:: Slab

   A slab descriptor: per-dimension half-open ranges into a stored tensor.

   For ``read_slice_etn`` and ``write_slice_etn``; `ranges[d]` is `{start, end}`, end exclusive.
   Captured by reference, so mutating `ranges` between replays drives one node over many slabs.

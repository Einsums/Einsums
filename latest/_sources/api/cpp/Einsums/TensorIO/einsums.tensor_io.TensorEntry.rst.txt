.. cpp:class:: TensorEntry

   Per-tensor metadata entry (160 bytes).


   .. cpp:function:: void init()

      Initialize to zeros.


   .. cpp:function:: bool permuted() const

      Whether the entry is stored in an axis order other than its declared one.


   .. cpp:function:: std::vector<size_t> stored_order() const

      The declared axis held at each stored position: element ``s`` names the declared axis stored
      ``s-th``, so the declared order is ``0, 1, ..., rank - 1``. Throws when the bytes do not name a
      permutation of the entry's axes, which only a damaged file holds.


   .. cpp:function:: void set_stored_order(const std::vector<size_t> &stored)

      Record ``stored``, a permutation of the entry's axes in the form ``stored_order`` returns.
      The declared order is recorded as all zero. Throws when ``stored`` is not a permutation of
      ``0, ..., rank - 1``.

.. cpp:function:: template <CoreBasicTensorConcept TensorType> void read_slice_etn(std::string file_path, std::string tensor_name, const Slab &slab, TensorType *output)

   Read a slab of a tensor from a .etn file, graph-aware.

   During capture, records a DiskRead node (see ``Slab``). ``output`` must already have the slab's
   shape, or execution throws.

   .. code-block:: text

      Slab slab{{ {0, 4}, {0, 4} }};
      tensor_io::read_slice_etn("integrals.etn", "ERI", slab, &block);

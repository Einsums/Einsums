.. cpp:function:: void remove_entry(std::string path, std::string name)

   Remove the entry ``name`` of ``path``.

   Its bytes become space later entries reuse; ``compact_file`` gives them back to the disk. See
   ``TensorFile::remove``.

   .. versionadded:: 2.0.0

   :throws std::runtime_error: when the file or the entry is missing.

einsums::gpu::not_implemented

.. cpp:namespace:: einsums::gpu

.. cpp:function:: void not_implemented(const char *what, const std::source_location loc)

   Report a GPU entry point that has no implementation on this backend.

   Throws, so a missing CUDA kernel is not mistaken for one that computed zeros. Callers that
   can fall back (the ComputeGraph executor) catch it.

   :param what: Name of the entry point, e.g. "gpu::solver::syev<float>".
   :param loc: Call site named in the message. Defaults to the caller's location.

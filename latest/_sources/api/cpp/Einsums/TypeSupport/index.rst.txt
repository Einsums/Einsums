Macros
------

- :c:macro:`EINSUMS_SINGLETON_DEF` - Makes a class a singleton with a static ``Type &get_singleton()``. Place at the start of the class, define a private no-argument constructor, and pair with ``EINSUMS_SINGLETON_IMPL``.
- :c:macro:`EINSUMS_SINGLETON_IMPL` - Creates the code for managing a singleton.

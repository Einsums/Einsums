============================
einsums::linear_algebra::svd
============================

.. note::
   Generated from the C++ headers by ``apiary --emit-cpp-docs-json``.

Defined in header ``Einsums/LinearAlgebra.hpp``.

.. cpp:namespace:: einsums::linear_algebra

.. cpp:function:: template <MatrixConcept AType> requires (CoreTensorConcept<AType>) std::tuple<std::optional<Tensor<typename AType::ValueType, 2>>, Tensor<RemoveComplexT<typename AType::ValueType>, 1>, std::optional<Tensor<typename AType::ValueType, 2>>> svd(const AType &A, Vectors jobu, Vectors jobvt)

   Computes the singular value decomposition.

   .. math::

      \mathbf{A} = \mathbf{U\SigmaV}^T

   Uses the original svd function found in lapack, gesvd, request all left and right vectors.

   .. versionadded:: 1.0.0

   .. versionchanged:: 2.0.0

      Now accepts a job specification and outputs optional tensors depending on the job.

   :tparam AType: The type of the input tensor.
   :param A: the matrix to decompose.
   :param jobu: Whether to compute the U matrix.
   :param jobvt: Whether to compute the transpose of the V matrix.
   :throws RankError: If the tensor being decomposed is not rank-2.
   :throws std::invalid_argument: If one of the parameters passed to the internal functions is invalid.
   :throws std::runtime_error: If the decomposition algorithm did not converge.
   :returns: A tuple containing the U matrix, singular value vector, and the transpose of the V matrix.

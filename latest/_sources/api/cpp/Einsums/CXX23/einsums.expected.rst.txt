einsums::expected

.. cpp:namespace:: einsums

.. cpp:class:: template <typename T, typename E> expected

   A value-or-error type (C++23 std::expected backport).

   Holds either a value of type T or an error of type E. The caller must
   check before accessing the value.

   **Example**

   .. code-block:: text

      einsums::expected<Settings, std::string> load_settings(path) {
          if (!file_exists(path))
              return einsums::unexpected("file not found: " + path);
          return Settings{...};
      }

      auto result = load_settings("settings.json");
      if (result) {
          use(result.value());
      } else {
          log_error(result.error());
      }

   :tparam T: Value type.
   :tparam E: Error type.

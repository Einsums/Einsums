einsums::hardware::write_profile

.. cpp:namespace:: einsums::hardware

.. cpp:function:: bool write_profile(const std::string &path, const json::Value &document, std::string &error)

   Write a profile document, atomically.

   Written to a temporary beside ``path`` and renamed into place, so a process reading the profile
   never sees half of one. Parent directories are created.

   .. versionadded:: 2.0.0

   :param path: Destination.
   :param document: The profile.
   :param error: Why it was not written, when it was not.
   :returns: Whether the file was written.

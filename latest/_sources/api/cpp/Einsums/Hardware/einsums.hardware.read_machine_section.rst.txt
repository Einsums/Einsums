.. cpp:function:: std::optional<MachineIdentity> read_machine_section(const json::Object &section, std::string &error)

   Read an identity back from a ``machine`` section.

   Every key the section must have is consumed, and the fingerprint is left for the caller, which
   compares it with the one it recomputes.

   .. versionadded:: 2.0.0

   :param section: The section.
   :param error: Why the section is unreadable, when it is.
   :returns: The identity, or nothing when a field is missing or of the wrong type.

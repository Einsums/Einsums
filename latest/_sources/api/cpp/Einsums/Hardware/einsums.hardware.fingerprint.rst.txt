einsums::hardware::fingerprint

.. cpp:namespace:: einsums::hardware

.. cpp:function:: std::string fingerprint(const MachineIdentity &identity)

   A short, stable name for an identity: 16 hexadecimal digits.

   A hash of the identity's canonical JSON, so two machines share a fingerprint exactly when every
   field agrees, and the same machine has the same one in every process and every build.

   .. versionadded:: 2.0.0

   :param identity: The identity.
   :returns: The fingerprint.

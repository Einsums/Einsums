.. cpp:function:: void set_num_threads(int nthreads)

   Set the OpenMP runtime's ceiling on a parallel region's team size.

   ``omp_set_num_threads()``, which also governs OpenMP-threaded BLAS; for a per-thread BLAS
   setting see ``einsums::blas::set_num_threads_this_thread``. A no-op without OpenMP.

   .. versionadded:: 2.0.0

   :param nthreads: Thread count ceiling to request.

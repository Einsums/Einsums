.. cpp:function:: bool import_profile(const std::string &path, std::string &message)

   Adopt a profile from another machine of a kind, or from a site.

   Checks the file against this machine and build and files it in the cache directory under its
   own machine's fingerprint, so one from another kind of machine is kept for that kind and never
   used here. A stale or invalid file is refused.

   .. versionadded:: 2.0.0

   :param path: The file.
   :param message: What happened, for the user.
   :returns: Whether the file was filed.

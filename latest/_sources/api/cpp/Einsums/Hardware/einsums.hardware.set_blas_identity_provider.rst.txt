einsums::hardware::set_blas_identity_provider

.. cpp:namespace:: einsums::hardware

.. cpp:function:: void set_blas_identity_provider(std::string (*provider)())

   Register the function that names the BLAS in use.

   The BLAS sits above this module, so it registers itself at start-up rather than this module
   reaching up for it. Until it does, the BLAS is named "unidentified".

   .. versionadded:: 2.0.0

   :param provider: Returns the name; called once, on first use of ``software_identity``.

einsums::blas::vendor::sger

.. cpp:function:: void sger(int_t m, int_t n, float alpha, const float *x, int_t inc_x, const float *y, int_t inc_y, float *a, int_t lda)

   Performs a rank-1 update of a general matrix.

   The ?ger routines perform a matrix-vector operator defined as

   .. math::

      \mathbf{A} := \alpha\mathbf{xy}^T + \mathbf{A}

   .. versionadded:: 1.0.0

   :param m: The number of elements in the left vector.
   :param n: The number of elements in the right vector.
   :param alpha: The scale factor for the product.
   :param x: The left vector.
   :param inc_x: The skip value for the left vector.
   :param y: The right vector.
   :param inc_y: The skip value for the right vector.
   :param a: The matrix to update.
   :param lda: The leading dimension of the matrix.
   :throws std::domain_error: If the dimensions are zero, or the leading dimension of the array is less than the number of columns.
   :throws std::invalid_argument: If either of the increment values is zero.

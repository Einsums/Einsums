.. cpp:function:: int_t ssterf(int_t n, float *d, float *e)

   Performs symmetric tridiagonal matrix diagonalization.

   .. versionadded:: 2.0.0

   :param n: The number of elements on the diagonal.
   :param d: The diagonal. On exit, it contains the eigenvalues.
   :param e: The subdiagonal.
   :returns: 0 on success. If positive, then the eigenvalue algorithm failed to converge. If negative, then one of the inputs had a bad value. The absolute value indicates which parameter it was.

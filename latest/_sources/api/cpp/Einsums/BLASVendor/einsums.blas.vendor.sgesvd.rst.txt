einsums::blas::vendor::sgesvd

.. cpp:function:: int_t sgesvd(char jobu, char jobvt, int_t m, int_t n, float *a, int_t lda, float *s, float *u, int_t ldu, float *vt, int_t ldvt, float *superb)

   Compute the singular value decomposition using the QR algorithm.

   .. versionadded:: 1.0.0

   :param jobu: Whether to compute the U vectors. Case insensitive. Can be either 'a', 's', 'o', or 'n'.
   :param jobvt: Whether to compute the V vectors. Case insensitive. Can be either 'a', 's', 'o', or 'n'.
   :param m: The number of rows of the matrix.
   :param n: The number of columns of the matrix.
   :param a: The matrix to decompose. Overwritten on exit.
   :param lda: The leading dimension of the input matrix.
   :param s: The singular values.
   :param u: The U vectors.
   :param ldu: The leading dimension of the U vectors. Must always be at least 1, even when not referenced.
   :param vt: The transpose of the V vectors.
   :param ldvt: The leading dimension of the transpose of the V vectors. Must always be at least 1, even when not referenced.
   :param superb: Storage space for intermediates used in the calculation.
   :returns: 0 on success. If positive, then the algorithm did not converge. If negative, then one of the parameters had an invalid value. The absolute value gives the parameter.

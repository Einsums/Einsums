einsums::blas::vendor::openblas_config

.. note::

.. cpp:namespace:: einsums::blas::vendor

.. cpp:function:: const char * openblas_config()

   The build configuration of the OpenBLAS that provides this process's dgemm.

   For example "OpenBLAS 0.3.34 NO_AFFINITY USE_OPENMP VORTEX". Asked of the library that actually
   resolved dgemm, not of the build, since a conda environment can swap the implementation behind
   libblas without a rebuild. Resolved once; the pointer lives as long as the library.

   .. versionadded:: 2.0.0

   :returns: The string from ``openblas_get_config``, or nullptr when the BLAS is not OpenBLAS.

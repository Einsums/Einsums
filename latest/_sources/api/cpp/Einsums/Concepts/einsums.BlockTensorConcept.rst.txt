===========================
einsums::BlockTensorConcept
===========================

.. note::
   Generated from the C++ headers by ``apiary --emit-cpp-docs-json``.

Defined in header ``Einsums/Concepts/TensorConcepts.hpp``.

.. cpp:namespace:: einsums

.. cpp:concept:: template <typename D, typename StoredType = void> BlockTensorConcept

   Checks to see if the tensor is a block tensor with the given storage type.

   Checks to see if the tensor inherits BlockTensorBaseNoExtra. If a type is given, also check to see if it inherits
   the appropriate CollectedTensorBaseOnlyStored.

   .. versionadded:: 1.0.0

   :tparam D: The tensor to check.
   :tparam StoredType: The type of the tensors stored in the collection, or void if you don't care.

einsums::hashes::ContainerHash

.. cpp:namespace:: einsums::hashes

.. cpp:class:: template <typename ContainerType> ContainerHash

   Hashes an arbitrary container object. Containers need to be iterable.

   Examples of allowed containers include std::array, std::vector, std::queue, etc.

   The default implementation is a PJW hash, based on the Wikipedia page.

   .. versionadded:: 1.0.0

   :tparam ContainerType: The type of container.

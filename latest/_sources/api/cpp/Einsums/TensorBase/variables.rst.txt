.. cpp:var:: inline constexpr int dynamic_rank

   Sentinel value for ``Tensor::Rank`` on tensor types whose rank is not known at compile time (e.g. ``GeneralRuntimeTensor``).

   Rank-comparing concepts treat it as a wildcard; runtime-rank checks are the caller's job.


.. cpp:var:: inline constexpr int kMaxSymmetryRank

   Maximum rank a symmetry operation can describe; smaller ranks are padded.

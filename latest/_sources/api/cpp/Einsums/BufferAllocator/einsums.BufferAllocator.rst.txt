einsums::BufferAllocator

.. cpp:namespace:: einsums

.. cpp:class:: template <typename T> BufferAllocator

   Allocator whose maximum size can be restricted by runtime variables.

   The limit is ``--einsums:buffer-size``. Avoid containers that resize often: a resize holds the old and new
   buffers at once, which can exceed the limit when the final size would not. A standard allocator.

   .. versionadded:: 1.1.0

   :tparam T: The data type returned by this allocator.

Classes
-------

- :cpp:any:`~einsums::BufferAllocator` - Allocator whose maximum size can be restricted by runtime variables.
- :cpp:any:`~einsums::MemoryPool` - A pre-reserved region of memory that mimalloc manages exclusively.
- :cpp:any:`~einsums::MemoryPoolEpoch` - RAII scope whose carves are released together when it closes.
- :cpp:any:`~einsums::MemoryPoolStats` - Accounting snapshot for one ``MemoryPool``.

Functions
---------

- :cpp:any:`~einsums::memory::aligned_alloc` - The library's one aligned-allocation primitive: 64-byte aligned, mimalloc-managed.
- :cpp:any:`~einsums::memory::aligned_free` - Release memory obtained from ``aligned_alloc``. Null is a no-op.
- :cpp:any:`~einsums::pool_reserve_cost` - The arena bytes a reservation of ``bytes`` actually claims, headroom and rounding included. Planners budgeting against einsums:max-memory should charge this, not the raw sum.
- :cpp:any:`~einsums::pooled_reserved_bytes` - Arena bytes currently charged against einsums:max-memory: every live pool, plus dead PINNED pools, whose pages stay resident. A dead unpinned pool's pages purge, so it stops counting when it dies.
- :cpp:any:`~einsums::register_Einsums_BufferAllocator_options` - Give the allocator's options their command-line presence. Idempotent.

Variables
---------

- :cpp:any:`~einsums::option::BufferSize` - Total memory the contraction buffers may hold. Catches a runaway temporary, with room for a wide machine running many contractions at once.
- :cpp:any:`~einsums::option::MaxMemory` - Ceiling on the memory einsums plans against: chunked algorithms size to it and MemoryPool refuses reservations past it. Ordinary allocations are not checked, so nothing throws in a kernel. 0 disables.
- :cpp:any:`~einsums::option::WorkBufferSize` - The largest piece of a disk-backed tensor a contraction reads into memory at once. Zero means an eighth of --einsums:buffer-size.

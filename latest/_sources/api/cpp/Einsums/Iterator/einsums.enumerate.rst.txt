.. cpp:function:: template <typename T, typename Iter> constexpr auto enumerate(T &&iterable, ptrdiff_t start)

   Mimic Python's enumerate.

   .. versionadded:: 1.0.0

   .. versionchanged:: 2.0.0

      Added the start parameter to match Python.

   :tparam T: The iterable type.
   :tparam Iter: The iterator type for the iterable.
   :param iterable: The iterable to iterate over.
   :param start: The starting value for the number element. Defaults to zero. Does not affect the start point in the iterator.


   Requires ``requires (T iterable) { { std::end(iterable) } -> std::same_as<Iter>; }``.

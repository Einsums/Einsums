einsums::compute_graph::alloc_state_name

.. cpp:namespace:: einsums::compute_graph

.. cpp:function:: std::string_view alloc_state_name(AllocState state) noexcept

   The name of an allocation state, for diagnostics and the saved form.

   Distinct from ``init_kind_name``, which says what a tensor is FILLED with. This says
   whether it has storage at all, which is what decides whether a bind may still reshape it.

   .. versionadded:: 2.0.0

   :param state: The state to name.
   :returns: A stable spelling ("materialized", "deferred").

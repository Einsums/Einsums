.. cpp:class:: ElementTransformDescriptor

   Metadata for ``OpKind::ElementTransform`` nodes whose kernel is NAMED.

   Applies the kernel registered under ``op_name`` to every element of the node's one output (also
   its one input). Lambda overloads record the kind with no descriptor, which cannot be saved;
   ``Graph::serializability_report`` names them.


   .. cpp:member:: static constexpr std::string_view descriptor_name

      The descriptor's name: its identity inside an ``OpData`` and in a saved graph.


   .. cpp:member:: std::string op_name

      Name of the kernel in the process's element-op registry.


   .. cpp:member:: std::optional<double> param

      The parameter of a parameterized kernel (e.g. a drop threshold). Empty means the default its
      registration documents, so files without the field still read.

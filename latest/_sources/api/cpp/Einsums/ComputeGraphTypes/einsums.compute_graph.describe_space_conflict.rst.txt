.. cpp:function:: std::string describe_space_conflict(const IndexSpace &held, const IndexSpace &offered)

   Name the fields two same-named spaces disagree on, with both values.

   So the message can say which declaration is repeated, e.g. two problem sizes deriving one space.

   :param held: What the registry already holds.
   :param offered: What the second declaration asked for.
   :returns: A comma-separated list such as ``"typical`` extent 4050 against 0", never empty for two spaces that compare unequal.

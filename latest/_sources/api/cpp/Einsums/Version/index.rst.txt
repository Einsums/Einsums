Version C++ API

- :cpp:any:`~einsums::build_date_time` - Returns the einsums build date and time
- :cpp:any:`~einsums::build_string` - Returns the einsums version string.
- :cpp:any:`~einsums::build_type` - Returns the einsums build type ('Debug', 'Release', etc.)
- :cpp:any:`~einsums::complete_version` - Returns the full version string.
- :cpp:any:`~einsums::configuration_string` - Return the einsums configuration information.
- :cpp:any:`~einsums::copyright` - Returns the copyright string.

- :cpp:any:`~einsums::minor_version` - Returns the minor einsums version.
- :cpp:any:`~einsums::patch_version` - Returns the sub-minor/patch-level einsums version.
- :cpp:any:`~einsums::tag` - Returns the tag.

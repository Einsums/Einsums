      The values in ``block_dims`` must be castable to size_t.

      .. code-block:: text

   .. cpp:function:: int block_of(size_t index) const

      Find the block which can be indexed by the given ``index``.

      This finds the block for which the ``index`` is within its range. Since these
      tensors are always square/hypercubic, the index is valid for all axes.
      This index should be greater than or equal to zero and less than the dimension
      of the tensor along any axis.

      .. versionadded:: 1.0.0

      :param index: The index to test.
      :throws std::out_of_range: Throws this when the index it outside of the tensor.
      :returns: The index of the block containing the given index.

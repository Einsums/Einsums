einsums::TiledTensorView

.. cpp:class:: template <typename T, size_t Rank> TiledTensorView final : public tensor_base::TiledTensor<T, Rank, TensorView<T, Rank>>, public tensor_base::CoreTensor

   Tensors of this class hold views of the tiles of a tiled tensor.

   Conceptually, this is a view of a TiledTensor. Practically, it stores a view of each of the tiles, allowing
   different slices to be taken from each. Since views of block tensors are not guaranteed to be truly block
   diagonal, TiledTensorViews also hold views of BlockTensors when the view is not hypersquare.


   .. cpp:function:: TiledTensorView() = default

   .. cpp:function:: template <typename... Sizes> TiledTensorView(std::string name, Sizes &&... sizes)

      Create an empty view with the given name and grid specification.

      One collection of tile sizes per axis, or a single one applied to every axis.

      :param name: The name of the tensor.
      :param sizes: The grids for the axes. There must either only be one, or the number must be the same as the rank.

      On exit, the structure of the copied tensor is copied. This means that the new tensor will view the same tensor

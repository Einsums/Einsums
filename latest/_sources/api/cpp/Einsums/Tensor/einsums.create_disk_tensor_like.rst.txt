einsums::create_disk_tensor_like

.. cpp:namespace:: einsums

.. cpp:function:: template <typename T, size_t Rank> DiskTensor<T, Rank> create_disk_tensor_like(hid_t file, const Tensor<T, Rank> &tensor)

   Create a disk tensor object.

   Creates a new tensor that lives on disk. This function does not create any tensor in memory
   but the tensor is "created" on the HDF5 ``file`` handle. Data from the provided tensor is NOT
   saved.

   .. code-block:: text

      auto mem_a = create_tensor("a", 3, 3);            // auto -> Tensor<double, 2>
      auto a = create_disk_tensor_like(handle, mem_a);  // auto -> DiskTensor<double, 2>

   :tparam T: The datatype of the underlying disk tensor, taken from ``tensor``.
   :tparam Rank: The rank of the tensor, taken from ``tensor``.
   :param file: The HDF5 file descriptor
   :param tensor: The tensor to reference for size and name.
   :returns: A new disk tensor.

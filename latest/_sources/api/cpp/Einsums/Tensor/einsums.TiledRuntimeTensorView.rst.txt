einsums::TiledRuntimeTensorView

.. cpp:namespace:: einsums

.. cpp:class:: template <typename T> TiledRuntimeTensorView : public tensor_base::CoreTensor, public tensor_base::TiledTensorNoExtra

   A non-owning, per-irrep-sliced view of a ``TiledRuntimeTensor``.

   Produced by ``TiledRuntimeTensor::view`` with one ``IndexSpace`` per axis.
   It does not own data: each populated tile is exposed as a
   ``RuntimeTensorView`` sub-block of the parent tile (via
   ``RuntimeTensor::at_view``), so a view like ``A[o, v, o, v]`` over an MO
   tensor selects the occ/vir sub-blocks of every symmetry-allowed tile with no
   copies. The parent must outlive the view.

   .. versionadded:: 2.0.0

   :tparam T: The data type stored in each tile.


   .. cpp:function:: TiledRuntimeTensorView() = default

   .. cpp:function:: TiledRuntimeTensorView(TiledRuntimeTensor<T> &parent, std::vector<IndexSpace> spaces, std::string name)

      Build a view of ``parent`` selecting ``spaces[k]`` along axis ``k``. One
      IndexSpace per axis, each covering every irrep on that axis. Computes the
      reduced per-axis tile sizes and global dims; no data is touched.

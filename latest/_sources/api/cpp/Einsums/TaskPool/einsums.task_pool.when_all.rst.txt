.. cpp:function:: template <typename T> TaskHandle<std::vector<T>> when_all(std::vector<TaskHandle<T>> handles)

   Fan-in: returns a handle that completes when all input handles complete.


.. cpp:function:: TaskHandle<void> when_all(std::vector<TaskHandle<void>> handles)

   Fan-in for void handles.


.. cpp:function:: template <typename... Ts> TaskHandle<std::tuple<Ts...>> when_all(TaskHandle<Ts>... handles)

   Variadic when_all: returns TaskHandle<std::tuple<T1, T2, ...>>.

   Completes when ALL input handles are ready. The result tuple contains
   the values in the same order as the input handles.

   .. code-block:: text

      auto a = pool.submit("a", []() { return 42; });
      auto b = pool.submit("b", []() { return 3.14; });
      auto combined = when_all(a, b);
      auto [x, y] = combined.get();  // x=42, y=3.14

.. cpp:function:: template <typename T = double> Tensor<T, 2> create_random_definite(const std::string &name, int rows, int cols, RemoveComplexT<T> mean)

   Create a random positive or negative definite matrix.
   A positive definite matrix is a symmetric matrix whose eigenvalues are all positive.
   Similarly for negative definite matrices.

   Random orthonormal eigenvectors P and Maxwell-Boltzmann eigenvalues D with mean ``mean`` give
   :math:`P^TDP`; a negative mean gives a negative definite matrix.

   .. versionadded:: 1.0.0

   :param name: The name for the matrix.
   :param rows: The number of rows.
   :param cols: The number of columns. Should equal the number of rows.
   :param mean: The mean for the eigenvalues. Defaults to 1.
   :returns: A new positive definite or negative definite matrix.

.. cpp:function:: template <CoreBasicTensorConcept TensorType> Tensor<typename TensorType::ValueType, TensorType::Rank> create_tensor_like(const TensorType &t)

   Creates a new tensor with the same rank and dimensions of the provided tensor.

   The tensor name will not be copied from the provided tensor. Be sure to call set_name on the new tensor.

   .. code-block:: text

      auto a = create_ones_tensor("a", 3, 3);          // auto -> Tensor<double, 2>
      auto b = create_tensor_like(a);                  // auto -> Tensor<double, 2>

   .. versionadded:: 1.0.0

   :tparam TensorType: The basic type of the provided tensor.
   :param t: The provided tensor to copy the dimensions from.
   :returns: A new tensor with the same rank and dimensions as the provided tensor.

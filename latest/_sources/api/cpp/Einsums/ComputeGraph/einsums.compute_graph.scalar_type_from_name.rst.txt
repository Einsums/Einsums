einsums::compute_graph::scalar_type_from_name

.. note::

.. cpp:namespace:: einsums::compute_graph

.. cpp:function:: std::optional<packed_gemm::ScalarType> scalar_type_from_name(std::string_view name) noexcept

   The element type spelled ``name``, if there is one.

   ``"unknown"`` resolves to ``packed_gemm::ScalarType::Unknown``, which is a
   legitimate thing for a handle to carry (an integral scalar has no BLAS type);
   a name that is not one of the five is the empty optional a loader reports.

   .. versionadded:: 2.0.0

   :param name: A spelling ``scalar_type_name`` produces.
   :returns: The type, or an empty optional when nothing is spelled that way.

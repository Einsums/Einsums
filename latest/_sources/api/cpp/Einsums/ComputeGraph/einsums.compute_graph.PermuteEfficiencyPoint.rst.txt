.. cpp:namespace:: einsums::compute_graph

.. cpp:class:: PermuteEfficiencyPoint

   A single measured permute (tensor transpose) data point.

   `gbps` is the achieved TRAFFIC rate, counting the source read and the
   destination write, so it is directly comparable with @ref
   DeviceProfile::mem_bandwidth_gbps from the copy benchmark.


   .. cpp:member:: size_t bytes

      Size of the permuted tensor (one side, not the traffic)


   .. cpp:member:: size_t rank

      Rank of the permuted tensor


   .. cpp:member:: double gbps

      Achieved (read + write) bandwidth

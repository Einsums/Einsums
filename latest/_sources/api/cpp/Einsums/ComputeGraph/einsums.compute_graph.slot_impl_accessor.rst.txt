einsums::compute_graph::slot_impl_accessor

.. cpp:namespace:: einsums::compute_graph

.. cpp:function:: template <typename TensorType> constexpr SlotImplAccessor slot_impl_accessor()

   The ``TensorSlot::impl_of`` accessor for one static tensor type.

   Kept here, beside the field it fills, so ``Graph::get_or_create_slot`` and
   ``Graph::rebind`` derive it the same way rather than each open-coding the
   ``if constexpr``.

   :tparam TensorType: The type the slot's ``TensorSlot::ptr`` addresses.
   :returns: A stateless function pointer, or null for a type with no single ``impl()`` (tile-wise sparse tensors).

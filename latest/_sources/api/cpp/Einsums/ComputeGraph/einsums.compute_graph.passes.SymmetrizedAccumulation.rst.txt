einsums::compute_graph::passes::SymmetrizedAccumulation
=======================================================

.. cpp:namespace:: einsums::compute_graph::passes

.. cpp:class:: SymmetrizedAccumulation : public OptimizerPass

   Fold the CCSD permutational-symmetrization idiom :math:`r2 \mathrel{+}= s\,(t + P(t))`.

   Chemistry residuals accumulate a tensor and its index-swapped transpose into
   the same output. In the graph this appears as four nodes per site (the
   ``symacc`` helper in ``ccsd_rhf_graph_numpy_style.py``):

   .. code-block:: text

      einsum(spec, A, B)            -> tmp    // tmp = pf*(A(x)B)   (kept)
      axpby(s, tmp,  1.0, r2)                 // r2 += s*tmp
      permute("jiba <- ijab", tmp) -> tmpP    // tmpP = P(tmp)   (an involution)
      axpby(s, tmpP, 1.0, r2)                 // r2 += s*tmp^{jiba}

   The pass detects each such site (structural match + involutive permutation +
   accumulate gate + interference guard) and rewrites it (Level 1, permute
   reuse). The permute node is made to accumulate DIRECTLY into the output,
   :math:`r2 = r2 + s_2\,\alpha\,P(t)`, rebuilt as an ordinary permute node with
   beta = 1 that keeps the permute's own alpha and permutation operators, and
   the second axpby and the ``tmpP`` buffer are deleted. The first axpby
   (:math:`r2 \mathrel{+}= s_1 t`) is untouched. This drops the O(o^2 v^2) ``tmpP``
   storage and one full sweep per site with no new kernel or OpKind. See
   ``docs/symmetrized_accumulation_design.md``.

   **Example (C++)**

   .. code-block:: text

      cg::Graph graph("symacc");
      {
          cg::CaptureGuard const capture(graph);
          cg::einsum("ijab <- ia ; jb", 0.0, &tmp, 1.0, A, B);  // tmp = A (x) B
          cg::axpby(0.5, tmp, 1.0, &r2);                         // r2 += 0.5*tmp
          cg::permute("jiba <- ijab", 0.0, &tmpP, 1.0, tmp);     // tmpP = P(tmp)
          cg::axpby(0.5, tmpP, 1.0, &r2);                        // r2 += 0.5*P(tmp)
      }
      graph.apply(cg::PassManager::create_default());
      // tmpP and the second axpby are gone; the permute now does r2 += 0.5*P(tmp).

   **Example (Python)**

   .. code-block:: py

      import einsums, einsums.graph as cg
      g = cg.Graph("symacc")
      with cg.capture(g):                                     # runtime tensors (the workload path)
          einsums.einsum("i,j,a,b <- i,a ; j,b", tmp, A, B)   # tmp = A (x) B
          einsums.linalg.axpby(0.5, tmp, 1.0, r2)             # r2 += 0.5*tmp
          einsums.permute("j,i,b,a <- i,j,a,b", tmpP, tmp)    # tmpP = P(tmp)
          einsums.linalg.axpby(0.5, tmpP, 1.0, r2)            # r2 += 0.5*P(tmp)
      sa = cg.SymmetrizedAccumulation()
      pm = cg.PassManager(); pm.add(sa)
      g.apply(pm)                                             # or cg.default_pass_manager()
      # sa.num_rewritten  -> 1   (getters are properties, not methods)

   In the default pipeline (after DeadNodeElimination, before ElementWiseFusion —
   which would otherwise compose the two axpby and hide the pattern). Recurses
   into loop bodies: the CCSD residual is captured as a loop body.

   **Limitations**

   - The source and the output must hold one element type, and a real output is never folded under a complex factor.
   - The source may be read through a view, but the output and ``tmpP`` may not be views: the folded node would write the output's parent storage, and ``tmpP`` must be storage no other id names. The source may not share the output's storage either, since the folded node reads one while writing the other.
   - Level 1 keeps the transpose (the accumulating permute), so REPLAY TIME is ~compute-neutral (a few %, transpose-bound). The win is eliminating the O(o^2 v^2) ``tmpP`` buffer (peak memory), not compute.
   - Detection requires the exact structure: an involutive overwrite permute whose output is consumed, within the generation this permute starts (up to the buffer's next overwrite), by exactly one accumulating axpby, plus a sibling accumulating axpby reading the un-permuted source into the same output from the source's own generation. Scratch REUSED across sites (the CCSD body recycles one tmp/tmpP for every term) matches per generation; an interference guard rejects sites where another node observes the half-symmetrized output.

   **Future improvements**

   - Level 2: a fused single-sweep ``SymmetrizedAxpby`` kernel (:math:`r2 \mathrel{+}= s_1 t + s_2 P(t)` in one pass), profiling-gated — drops the second sweep as well, not just the buffer.
   - Generalize beyond involutive permutations and allow :math:`s_1 \neq s_2`.
   - Accept a view as the output: the folded node reaches it through its impl, so what is left is proving the interference guard sees every other view of it.

      Not a node that writes a view, nor a redirected slot. The folded permute is built from the matched one's descriptor, operators
      and scalars included, and reads its operands through their impls, so a view read and a complex prefactor are understood.

      The folded form accumulates the same terms; measured at exactly zero on all six legs.


   .. cpp:function:: std::vector<std::string> explain() const override

      See ``OptimizerPass::explain``.


   .. cpp:function:: void reset_stats() override

   .. cpp:function:: bool recurse_into_subgraphs() const override

      False, and the pass walks the sub-graph tree itself. The CCSD residual is a loop body whose
      scratch the enclosing graph declares, and folding a site stops writing that scratch; only a
      walk that carries what the rest of the program reads down into each body can tell whether
      anything outside the body would see the value go stale.


   .. cpp:function:: size_t num_candidates() const

      Structural matches: permute (involutive, overwrite) whose output feeds,
      within the generation this permute starts, exactly one accumulating
      axpby into an output that a sibling accumulating axpby also feeds from
      the un-permuted source's generation.


   .. cpp:function:: size_t num_matched() const

      Candidates that also pass the interference guard (no other node observes
      the half-symmetrized output or rewrites the source mid-fold) - the sites
      that are safe to fold.


   .. cpp:function:: size_t num_rewritten() const

      Sites actually rewritten (num_matched that also passed the dtype and
      operand gates). Each eliminates one axpby and one tmpP buffer.

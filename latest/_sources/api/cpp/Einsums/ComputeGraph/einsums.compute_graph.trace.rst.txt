einsums::compute_graph::trace

.. cpp:namespace:: einsums::compute_graph

.. cpp:function:: template <RuntimeRankTensorConcept AType> typename AType::ValueType trace(const AType &A)

   Trace of a square matrix: ``sum(A_ii)``. Returns the scalar.

   Cannot be used during graph capture (returns by value, so there is no
   destination slot). For the in-graph form use the four-argument
   ``cg::trace(&result, A)`` with a pre-allocated scalar.


.. cpp:function:: template <MatrixConcept AType> void trace(typename AType::ValueType *result, const AType &A)

   Graph-aware trace writing the result to a pre-allocated scalar.

   :tparam AType: A square rank-2 tensor type satisfying ``MatrixConcept``.
   :param result: Pointer to the destination scalar; populated at execute.
   :param A: Source tensor; ``A.dim(0) == A.dim(1)`` is required.

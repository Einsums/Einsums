einsums::compute_graph::ExprIndex

.. cpp:namespace:: einsums::compute_graph

.. cpp:class:: ExprIndex

   One index of a term, with the space it ranges over.

   The space may be invalid, which means the slot this letter met carried no
   annotation. That is not an error and must not be treated as one: a partially
   annotated program yields partial spaces rather than no expression, exactly as
   ``SymbolicVar``'s anonymous flavour yields a weaker comparison rather than no
   comparison.


   .. cpp:member:: std::string letter

      The index letter, used verbatim including a multi-character name.


   .. cpp:member:: SpaceId space

      The space this letter ranges over here, or an invalid id.

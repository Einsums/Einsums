einsums::compute_graph::axpby

.. cpp:function:: template <TensorConcept XType, TensorConcept YType> requires SameUnderlying<XType, YType> void axpby(typename XType::ValueType alpha, const XType &X, typename XType::ValueType beta, YType *Y)

   Graph-aware AXPBY: ``Y = alpha * X + beta * Y`` (extended BLAS level-1).

   Like ``axpy`` but also scales the destination by ``beta`` first.
   X and Y must have the same dtype and shape.

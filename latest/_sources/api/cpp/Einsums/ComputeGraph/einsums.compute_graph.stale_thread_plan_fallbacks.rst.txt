einsums::compute_graph::stale_thread_plan_fallbacks
===================================================

.. note::
   Generated from the C++ headers by ``apiary --emit-cpp-docs-json``.

Defined in header ``Einsums/ComputeGraph/Executor.hpp``.

.. cpp:namespace:: einsums::compute_graph

.. cpp:function:: std::size_t stale_thread_plan_fallbacks()

   Replays that ignored their thread plan because the machine changed.

   ``DataflowExecutor`` runs every node at width 1 when a graph's
   ``Graph::planned_thread_count`` no longer matches the thread count the
   budget is rationing, and warns once. The count is the machine-readable half
   of that warning: a fallback is a silent performance cliff otherwise, and a
   test cannot assert on a log line.

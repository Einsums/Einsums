einsums::compute_graph::truncated_svd
=====================================

.. cpp:namespace:: einsums::compute_graph

.. cpp:function:: template <RuntimeRankTensorConcept AType> std::tuple<GeneralRuntimeTensor<typename AType::ValueType, std::allocator<typename AType::ValueType>>, GeneralRuntimeTensor<RemoveComplexT<typename AType::ValueType>, std::allocator<RemoveComplexT<typename AType::ValueType>>>, GeneralRuntimeTensor<typename AType::ValueType, std::allocator<typename AType::ValueType>>> truncated_svd(const AType &A, size_t k)

   Rank-``k`` truncated SVD (returning): keeps the top ``k`` singular
   triples of ``A``. Returns ``(U_k, S_k, Vt_k)`` with ``U_k`` of shape
   ``(m, k)``, ``S_k`` of shape ``(k,)``, and ``Vt_k`` of shape ``(k, n)``.

   Randomized algorithm with over-sampling factor 5, which requires
   ``A.dim(0) >= k + 5``. Smaller inputs raise ``IndexError`` from the
   projection step. Results are approximate; expect small drift versus a
   full ``svd``.

   Cannot be used during graph capture (returns by value); ``A`` is left
   unmodified.

.. cpp:class:: GroupedAxpbyDescriptor

   Metadata for ``OpKind::GroupedAxpby`` nodes.

   The prefactors are PER ENTRY, which is the whole difference from
   ``AxpbyDescriptor``: a grouped call exists to merge accumulations that
   disagree on their coefficients. Snapshots only, and there is deliberately no
   shared-params handle: ScaleAbsorption and friends fold a scale into a single
   axpby by rewriting one live scalar, and doing that to one entry of a run would
   need the pass to know which entry, which no pass does yet.


   .. cpp:member:: static constexpr std::string_view descriptor_name

      The descriptor's name: its identity inside an ``OpData`` and in a saved graph.


   .. cpp:member:: int total

      How many axpby operations the node holds.

      Per-entry alpha, in entry order.

      Per-entry beta, in entry order.

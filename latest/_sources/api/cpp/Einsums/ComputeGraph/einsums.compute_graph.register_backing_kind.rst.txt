einsums::compute_graph::register_backing_kind
=============================================

.. note::

Defined in header ``Einsums/ComputeGraph/TensorBacking.hpp``.

.. cpp:namespace:: einsums::compute_graph

.. cpp:function:: void register_backing_kind(BackingKind kind)

   Register ``kind`` so a saved graph naming it can be loaded.

   Do it from a namespace-scope initializer in the module that knows the storage. Registration is
   thread-safe.

   :throws std::invalid_argument: when the name is not qualified, is already registered, or when ``BackingKind::open`` is empty.

einsums::compute_graph::MatrixOperand
=====================================

.. note::
   Generated from the C++ headers by ``apiary --emit-cpp-docs-json``.

Defined in header ``Einsums/ComputeGraph/Operations.hpp``.

.. cpp:namespace:: einsums::compute_graph

.. cpp:concept:: template <typename T> MatrixOperand

   A rank-2 operand of the BLAS and LAPACK wrappers below: either a tensor that
   fixes rank 2 in its type, or a runtime-rank tensor whose rank the wrapper
   checks at the call. One body serves both families, so one constraint names
   both.

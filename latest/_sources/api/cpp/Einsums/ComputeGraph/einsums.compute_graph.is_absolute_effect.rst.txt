.. cpp:function:: constexpr bool is_absolute_effect(ApproximationEffect effect) noexcept

   Whether ``effect`` is an ABSOLUTE bound rather than a relative one.

   The one place the absolute/relative split is written down, because a comparison has to
   decide which of its two knobs a bound widens and two answers to that would drift.

   .. versionadded:: 2.0.0

   :param effect: The effect to classify.
   :returns: True for ``ApproximationEffect::ElementWise`` and ``ApproximationEffect::EnergyLike``.

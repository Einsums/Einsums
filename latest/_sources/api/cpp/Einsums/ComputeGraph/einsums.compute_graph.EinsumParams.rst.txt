.. cpp:class:: EinsumParams

   Mutable scalar parameters for einsum operations.

   Stored in a shared_ptr so the executor lambda captures it by shared
   ownership. Updating the values changes the computation on next execute().

   Both prefactors are ``PrefactorScalar`` variants, they hold one of
   float/double/complex<float>/complex<double>. The executor extracts the
   concrete scalar via ``as<T>`` when dispatching to typed BLAS.


   .. cpp:member:: PrefactorScalar c_pf

      C prefactor


   .. cpp:member:: PrefactorScalar ab_pf

      AB prefactor


   .. cpp:member:: bool conj_a

      Conjugate A (complex; no-op for real)


   .. cpp:member:: bool conj_b

      Conjugate B (complex; no-op for real)

.. cpp:namespace:: einsums::compute_graph

.. cpp:class:: EventLog : public ExecutionObserver

   An observer that keeps every event, for reading after the replay: the way to observe a replay from Python, whose callbacks would serialize the executors on the GIL.

   .. code-block:: text

      log = cg.EventLog()
      g.set_observer(log)
      g.execute()
      slowest = sorted((e for e in log.events if e.kind == cg.EventKind.NodeEnd), key=lambda e: e.ms)[-5:]
      log.write_chrome_trace("replay.json")      # open in ui.perfetto.dev

   .. versionadded:: 2.0.0

   .. cpp:function:: void write_chrome_trace(const std::string &path) const

      Write the events as a Chrome trace: one track per thread, a span per node, an instant per storage event, readable in ``ui.perfetto.dev`` or ``chrome://tracing``.

      :param path: The file to write.
      :throws std::runtime_error: when the file cannot be written.

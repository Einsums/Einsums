einsums::compute_graph::ger

.. cpp:function:: template <MatrixOperand AType, VectorOperand XType, VectorOperand YType> requires SameUnderlying<AType, XType, YType> void ger(typename AType::ValueType alpha, const XType &X, const YType &Y, AType *A)

   Graph-aware GER (rank-1 update): ``A += alpha * X * Y^T``.

   Outer product of vectors X and Y added to matrix A. X and Y must be
   rank 1; A must be rank 2.

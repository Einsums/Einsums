einsums::compute_graph::ExecutionEvent

.. cpp:namespace:: einsums::compute_graph

.. cpp:class:: ExecutionEvent

   One thing that happened while a replay ran.

   Every event carries the fields its kind has: a node event its node, a storage event its tensor,
   storage and bytes. ``at_ms`` is measured from the start of the outermost replay on one steady
   clock, so events from different threads order by it.

   .. versionadded:: 2.0.0

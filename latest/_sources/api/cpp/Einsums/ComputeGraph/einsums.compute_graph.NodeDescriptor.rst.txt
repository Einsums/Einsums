======================================
einsums::compute_graph::NodeDescriptor
======================================

.. note::
   Generated from the C++ headers by ``apiary --emit-cpp-docs-json``.

Defined in header ``Einsums/ComputeGraph/Node.hpp``.

.. cpp:namespace:: einsums::compute_graph

.. cpp:concept:: template <typename D> NodeDescriptor

   A type ``OpData`` can hold: a copyable struct naming itself with a ``static constexpr std::string_view descriptor_name``.

   The name is the descriptor's identity, both inside an ``OpData`` and in a
   saved graph, so it must be unique; by convention it is the type's own name.
   Nothing else is required, so a descriptor may be declared anywhere, including
   outside this library.

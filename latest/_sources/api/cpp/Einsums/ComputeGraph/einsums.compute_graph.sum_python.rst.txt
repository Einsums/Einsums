einsums::compute_graph::sum_python
==================================

.. cpp:namespace:: einsums::compute_graph

.. cpp:function:: template <CoreBasicTensorConcept ResultType, CoreBasicTensorConcept AType> requires (std::is_same_v<typename ResultType::ValueType, typename AType::ValueType>) void sum_python(ResultType *result, const AType &A)

   Graph-aware sum of every element, written into ``result->data()[0]``.

   Mirrors dot_python's scalar-into-[1]-tensor convention: eager when not
   capturing, an opaque ``OpKind::Custom`` node otherwise. Stride-correct
   (works on slice/transpose views). Backs the numpy-style ``A.sum()`` /
   ``A.mean()``.

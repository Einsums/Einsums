.. cpp:namespace:: einsums::compute_graph

.. cpp:class:: Region

   A contiguous run of raisable nodes, and what crosses its boundary.

   **Why contiguous**

   A region's replacement is spliced over its nodes, so a region whose nodes are
   interleaved with nodes it does not contain would have to prove that splicing
   at one position preserves every dependency the interleaved nodes have. That
   proof is exactly the reasoning the program-order guard in `PassManager::run`
   exists because passes got wrong (GEMMBatching appended a writer past a
   surviving reader; LCCF was bitten by the same trap earlier). A maximal run of
   CONSECUTIVE raisable nodes needs no such proof, and it is deliberately the
   first cut: growing to non-contiguous regions is a later extension that has to
   bring the reasoning with it.

   **Barriers**

   Anything not in the raisable set ends a run: LAPACK, control flow,
   communication, I/O, lifecycle, an anonymous ``OpKind::ElementTransform``
   whose kernel has no registered name, and a node carrying a feature outside
   ``RegionOptions::understood``. A method whose body is not flat therefore
   gets a declined rewrite naming the barrier rather than a silently smaller
   region.

einsums::compute_graph::make_provenance_tag

.. cpp:function:: ProvenanceTag make_provenance_tag(std::string name, std::vector<std::pair<std::string, std::string>> attributes)

   Build a ``ProvenanceTag``.

   A named constructor rather than a real one, for the same reason ``make_index_space`` is one:
   ``ProvenanceTag`` stays an aggregate so the library's designated-initializer construction
   sites keep working, and this is what a caller with no aggregate initialization builds one
   through.

   Both parameters are required rather than the second defaulted, which is a binding constraint
   rather than a preference: the codegen renders a ``= {}`` default as a bare brace-init that
   pybind's ``py::arg`` cannot be assigned from. The Python-side helper in ``einsums.graph``
   supplies the empty list, so a caller there still writes just the name.

   .. versionadded:: 2.0.0

   :param name: The vocabulary name.
   :param attributes: Key/value pairs, possibly empty. Sorted by ``Graph::annotate_tag`` on the way in, so the order given here does not matter.
   :returns: The tag.

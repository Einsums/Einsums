.. cpp:function:: bool is_raisable(OpKind kind)

   Whether a node kind can be raised into the algebra.

   Everything outside this set is a barrier, which is a
   statement about what the IR can faithfully represent rather than about what is
   interesting: a kind that raises has to lower back to the same arithmetic, and
   a kind whose descriptor the IR cannot rebuild would round-trip into something
   else.

   :param kind: The op kind.
   :returns: True when a node of this kind may join a region.

.. cpp:class:: NaryEinsumFormatString

   An einsum spec over three or more operands, its structure checked at compile time.

   The same check ``EinsumFormatString`` makes, but for two or more ``;`` separators. A runtime
   string converts unchecked, and is parsed when the einsum runs.

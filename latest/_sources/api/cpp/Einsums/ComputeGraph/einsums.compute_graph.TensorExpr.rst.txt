   .. cpp:function:: std::string to_string(const SpaceRegistry *registry) const

      A one-line-per-statement rendering, for a report or a test.

      Reads as algebra rather than as a node list: ``C[i,j] += 2 * A[i,k] B[k,j]``.
      A diffable before-and-after of THIS is a far better bug report than a
      diff of two node dumps, which is the whole argument for dumping at all.

      :param registry: Space registry to name spaces through, or nullptr to print letters alone.
      :returns: The rendering, one statement per line, newline-terminated.

einsums::compute_graph::SliceRequest

.. cpp:namespace:: einsums::compute_graph

.. cpp:class:: SliceRequest

   Which axes of a node's operands one slice drops, and where the index of each is.

   Indexed [operand][axis], the output first and then each input in the node's order. An entry
   names the ``ParamTable`` entry holding the dropped axis's index on this iteration; an empty
   entry is an axis the slice keeps whole. A sliced node reads that parameter, so its descriptor's
   ``accesses`` hook must declare it.

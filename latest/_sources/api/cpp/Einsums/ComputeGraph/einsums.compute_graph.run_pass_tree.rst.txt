einsums::compute_graph::run_pass_tree

.. cpp:namespace:: einsums::compute_graph

.. cpp:function:: bool run_pass_tree(OptimizerPass &pass, Graph &graph)

   Run ``pass`` on ``graph`` and, when the pass opts into sub-graph recursion, on every descendant loop body and branch.

   The one recursion driver: PassManager and Graph::apply both go through it, so a pass reaches
   the same graphs however it is applied.

   :returns: Whether any invocation modified its graph.

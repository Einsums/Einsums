.. cpp:class:: BackingCounters

   What a backing's storage has moved, counted as it happens.

   Relaxed atomics: slabs are read and written on whichever thread runs the node, and the counts
   are read only between replays. ``Graph::annotate_backing`` attaches a fresh set to each backing
   it accepts, and ``RunMetrics`` reports one replay's share as the difference of two readings.

   .. versionadded:: 2.0.0


   .. cpp:member:: std::shared_ptr<detail::RunContext> context

      The run context of the graph that accepted the backing, which tells an attached observer
      (``ExecutionObserver``) what the storage moves.

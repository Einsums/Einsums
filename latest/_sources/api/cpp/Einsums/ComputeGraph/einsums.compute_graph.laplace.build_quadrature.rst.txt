.. cpp:function:: QuadratureGrid build_quadrature(const SpectralRange &range, double epsilon, std::size_t points)

   Build the rule at a fixed point count.

   .. versionadded:: 2.0.0

   :param range: The spectral range of the signed sum. Must not contain zero.
   :param epsilon: The target relative accuracy, which fixes where the grid is truncated.
   :param points: How many points to use. Must be at least two.
   :throws std::invalid_argument: When ``range`` straddles or touches zero, when ``epsilon`` is not a usable tolerance, or when ``points`` is below two.
   :returns: The rule.

einsums::compute_graph::real

.. cpp:function:: template <typename ResultType, typename AType> requires DenseOrTiled<ResultType> && DenseOrTiled<AType> void real(ResultType *out, const AType &A)

   Graph-aware real part: ``out := Re(A)``. Complex ``A`` produces real ``out``.
   For real ``A`` it is a copy, since Re(x) == x, matching numpy ``.real``. Dense
   or tiled.

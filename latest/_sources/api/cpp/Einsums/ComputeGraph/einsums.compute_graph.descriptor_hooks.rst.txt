.. cpp:namespace:: einsums::compute_graph

.. cpp:function:: const DescriptorHooks * descriptor_hooks(const Node &node) noexcept

   The hooks registered for ``node's`` descriptor, or null.

   Null unless ``node`` is an ``OpKind::Custom`` node whose descriptor has a registered codec. A
   library descriptor's name is never qualified, so only a registered one is looked up. The
   returned table lives for the rest of the process.

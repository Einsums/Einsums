einsums::compute_graph::ApproximationTolerance

.. cpp:namespace:: einsums::compute_graph

.. cpp:class:: ApproximationTolerance

   The comparison tolerance a set of approximation records implies.

   Two numbers rather than one because the effects do not share units: an absolute bound
   widens the absolute side of a comparison and a relative one widens the relative side.
   Which is which is ``is_absolute_effect``, in one place.

   Both zero means the graph carries no records, which is exact mode and today's behavior.

   .. seealso::

      Graph::approximation_tolerance

   .. versionadded:: 2.0.0

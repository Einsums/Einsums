einsums::compute_graph::invert
==============================

.. note::
   Generated from the C++ headers by ``apiary --emit-cpp-docs-json``.

Defined in header ``Einsums/ComputeGraph/Operations.hpp``.

.. cpp:namespace:: einsums::compute_graph

.. cpp:function:: template <MatrixOperand AType> void invert(AType *A)

   In-place matrix inverse: ``A := A^-1``.

   ``A`` must be rank 2 and square. Internally calls ``getrf`` followed
   by ``getri``; raises ``RankError`` if the input rank is wrong and
   the LAPACK kernel raises if ``A`` is singular.

.. cpp:function:: void register_descriptor(DescriptorCodec codec)

   Register ``codec`` for the descriptor named ``codec.name``.

   Do it before capturing, saving or loading a graph that uses the descriptor, typically from a
   namespace-scope initializer in the code that declares it. Registration is thread-safe.

   :throws std::invalid_argument: when the name is not qualified, is already registered, or when any of the three functions is empty.

   Register a codec for ``D`` from functions over ``D`` itself, with hooks.

   As the three-function form, plus ``hooks``, whose empty members stay empty.


.. cpp:function:: template <NodeDescriptor D, typename Write, typename Read, typename Build> void register_descriptor(Write write, Read read, Build build)

   Register a codec for ``D`` from functions over ``D`` itself.

   ``write`` takes a ``D const &`` and returns a ``json::Value``; ``read`` takes a
   ``json::Object const &`` and returns a ``D``; ``build`` takes a ``D const &`` followed by the
   arguments of ``DescriptorCodec::build``. The codec has no hooks.

.. cpp:function:: void transfer_graph_registration(const Graph *from, Graph *to)

   Point the registry entry for ``from`` at ``to``, for a graph that moved.

   Unlike an unregister followed by a register, nothing is cached for ``from``, whose contents
   now live in ``to``, and a graph captured but never executed stays listed. A no-op when ``from``
   is not registered.

   :param from: The graph's address before the move.
   :param to: Its address after.

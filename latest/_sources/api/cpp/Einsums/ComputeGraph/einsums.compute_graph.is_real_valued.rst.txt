einsums::compute_graph::is_real_valued
======================================

.. note::
   Generated from the C++ headers by ``apiary --emit-cpp-docs-json``.

Defined in header ``Einsums/ComputeGraph/Prefactor.hpp``.

.. cpp:namespace:: einsums::compute_graph

.. cpp:function:: bool is_real_valued(const PrefactorScalar &v)

   True iff the contained value carries no imaginary component (real
   alternatives always qualify). Passes that flatten prefactors into real
   arithmetic must gate on this rather than silently truncating with
   ``as_real``.

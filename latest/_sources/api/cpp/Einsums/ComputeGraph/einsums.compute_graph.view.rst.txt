.. cpp:function:: template <typename T, size_t Rank, CoreBasicTensorConcept ParentT, typename... Axes> TensorView<T, Rank> & view(ParentT &parent, Axes &&... axes)

   Record a non-owning slice of a tensor.

   Records a ``OpKind::View`` node and returns a graph-owned slice that
   downstream operations can consume. ``parent`` must outlive the graph.

   :tparam T: Element type.
   :tparam Rank: Rank of the resulting view (currently must match parent's rank).
   :tparam ParentT: Parent tensor type (any ``CoreBasicTensorConcept`` value).
   :tparam Axes: Pack of ``ViewAxis``. Use ``ViewAxis::full()`` and ``ViewAxis::range(lo, hi)`` to construct.
   :param parent: The tensor being sliced.
   :param axes: One ViewAxis per parent rank.
   :returns: Reference to a graph-owned ``TensorView<T, Rank>`` that subsequent ``cg::*`` calls (einsum, gemm, …) can consume by value/reference.

.. cpp:class:: BoundExpr

   A scalar integer expression that can be resolved at execute time.

   Used to specify slice bounds on ``ViewDesc`` and similar runtime-resolvable
   scalars. A ``BoundExpr`` is one of:

   - **Const**:    a known integer literal (e.g. ``0``, ``5``).
   - **Param**:    a named lookup into a ``ParamTable``. Resolved by walking the active pipeline's parameter table at execute time. Codegen emits ``params.<name>``.
   - **Callback**: a ``std::function<int64_t()>`` evaluated at execute time. Most flexible but interpreted-mode only, since codegen has to either fall back to a thunk or refuse the graph.

   Implicit conversions are provided so callers can write
   ``cg::Range{0, 5}``, ``cg::Range{0, "n_occ"}``, or
   ``cg::Range{0, [&]{ return n_occ; }}`` interchangeably.

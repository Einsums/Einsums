einsums::compute_graph::svd

.. cpp:namespace:: einsums::compute_graph

.. cpp:function:: template <RuntimeRankTensorConcept AType> std::tuple<GeneralRuntimeTensor<typename AType::ValueType, std::allocator<typename AType::ValueType>>, GeneralRuntimeTensor<RemoveComplexT<typename AType::ValueType>, std::allocator<RemoveComplexT<typename AType::ValueType>>>, GeneralRuntimeTensor<typename AType::ValueType, std::allocator<typename AType::ValueType>>> svd(const AType &A)

   Singular value decomposition (returning): ``A = U * diag(S) * Vt``.

   Returns the tuple ``(U, S, Vt)``. ``S`` is real even for complex
   inputs. ``U`` and ``Vt`` are always present, and the user can post-
   filter for the "no vectors" case if needed. Cannot be used during
   graph capture (returns by value); ``A`` is left unmodified.

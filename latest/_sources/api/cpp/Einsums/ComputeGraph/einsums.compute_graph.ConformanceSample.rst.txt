einsums::compute_graph::ConformanceSample

.. cpp:namespace:: einsums::compute_graph

.. cpp:class:: ConformanceSample

   One case ``check_descriptor`` runs a registered descriptor's node on.

   The kit builds several one-node graphs from each sample and compares what their outputs hold
   byte for byte, so ``operands`` must produce the same values every time it is called.


   .. cpp:member:: std::string name

      Names the sample in a reported problem.


   .. cpp:member:: OpData descriptor

      The descriptor the node carries.


   .. cpp:member:: packed_gemm::ScalarType dtype

      The element type and rank the node's executor is built for, as for ``record_built``.


   .. cpp:member:: std::size_t rank

   .. cpp:member:: std::function<ConformanceOperands (Graph &)> operands

      Creates the node's tensors in ``graph``, which is capturing, fills its inputs and its
      outputs' prior contents, and returns their ids. Make dense tensors the graph owns
      (``graph.create_runtime_tensor<T>(name, dims, false)``) so nothing outlives the graph.


   .. cpp:member:: std::map<std::string, std::int64_t> params

      The parameters the node's executor may read, set on each graph before capture.


   .. cpp:member:: unsigned int width

      The width a moldable node is run at to compare against width 1; 0 means the machine's
      thread count.


   .. cpp:member:: double width_tolerance

      The relative difference allowed between the two, for a kernel whose reduction order
      changes with the thread count. Zero demands the same bytes.

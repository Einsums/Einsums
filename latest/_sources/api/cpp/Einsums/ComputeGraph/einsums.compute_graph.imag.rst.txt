einsums::compute_graph::imag
============================

.. note::
   Generated from the C++ headers by ``apiary --emit-cpp-docs-json``.

Defined in header ``Einsums/ComputeGraph/Operations.hpp``.

.. cpp:namespace:: einsums::compute_graph

.. cpp:function:: template <typename ResultType, typename AType> requires DenseOrTiled<ResultType> && DenseOrTiled<AType> void imag(ResultType *out, const AType &A)

   Graph-aware imaginary part: ``out := Im(A)``. Complex ``A`` produces real
   ``out``. For real ``A`` it is zeros, since Im(x) == 0, matching numpy
   ``.imag``. Dense or tiled.

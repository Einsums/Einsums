einsums::compute_graph::escape_reason

.. cpp:function:: std::string_view escape_reason(Escape reason)

   A short, shape-independent phrase for ``reason``, suitable for ``note_skip``.

   Shape-independent on purpose: `OptimizerPass::note_skip` aggregates by reason
   string, so a phrase carrying a tensor name would produce one line per
   candidate instead of one line with a count.

   :param reason: The verdict to name.
   :returns: The phrase, e.g. ``"a node outside the region reads it"``.

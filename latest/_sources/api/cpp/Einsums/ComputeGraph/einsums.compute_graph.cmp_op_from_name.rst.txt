.. cpp:namespace:: einsums::compute_graph

.. cpp:function:: std::optional<CmpOp> cmp_op_from_name(std::string_view name) noexcept

   The ``CmpOp`` spelled ``name``, if there is one.

   The reverse of ``cmp_op_name``, for the IR's by-name rule: a saved predicate
   writes "lt", never the enumerator's numeric value.

   .. versionadded:: 2.0.0

   :param name: A spelling ``cmp_op_name`` produces.
   :returns: The operator, or an empty optional when nothing is spelled that way.

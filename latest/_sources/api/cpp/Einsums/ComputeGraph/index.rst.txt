Macros
------

- :c:macro:`EINSUMS_CG_COMMON_TENSOR_TYPES_FOR` - The tensor types the library precompiles ComputeGraph's per-tensor-type templates for: dense tensors and views of rank 1 to 4 and the runtime-rank tensor and view, over the four element types. Each header that declares such a template ``extern`` for these types, and the source that instantiates it, applies ``X`` to each type through this one list, so the two cannot drift apart. Any other type instantiates the template where it is used.
- :c:macro:`EINSUMS_CG_ELEMENT_TYPES` - The element types the library precompiles ComputeGraph's per-element-type templates for, such as ``Graph``'s tensor factories. ``X`` is applied to each.
- :c:macro:`EINSUMS_CG_REAL_ELEMENT_TYPES` - The real element types, for the operations that have no complex form (sqrt, max, the sandwich kernels). ``X`` is applied to each.

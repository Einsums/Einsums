.. cpp:namespace:: einsums::compute_graph

.. cpp:function:: std::vector<std::string> named_reads(const Node &node)

   Every named resource outside the tensor dataflow this node READS, as ordering keys: ``param_reads`` and the dataset a ``DiskRead`` loads, plus, for a control-flow node, every key read anywhere in its child graphs, plus the named reads a registered descriptor's ``accesses`` hook reports. See ``named_writes``.

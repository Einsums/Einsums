einsums::compute_graph::passes::permutation_of

.. cpp:namespace:: einsums::compute_graph::passes

.. cpp:function:: std::optional<std::vector<std::size_t>> permutation_of(const std::vector<std::string> &a, const std::vector<std::string> &c)

   Where each of ``c's`` letters sits in ``a``, when ``c`` is a permutation of ``a``.

   Returns ``perm`` with ``c[k] == a[perm[k]]``, or nothing when the lists differ in length, a
   letter repeats in either, or a letter of one is missing from the other. A repeated letter makes
   the permutation ambiguous, so it is refused rather than resolved.

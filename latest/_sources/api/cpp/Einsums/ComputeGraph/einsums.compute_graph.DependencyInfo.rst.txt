einsums::compute_graph::DependencyInfo

.. cpp:namespace:: einsums::compute_graph

.. cpp:class:: DependencyInfo

   Dependency information for a sorted graph.

   Computed by Graph::topological_sort() and stored for reuse by executors.
   Indices refer to positions in the sorted nodes vector.


   .. cpp:member:: std::vector<std::vector<size_t>> successors

      successors[i] = nodes that depend on node i


   .. cpp:member:: std::vector<std::vector<size_t>> predecessors

      predecessors[i] = nodes that node i depends on


   .. cpp:member:: std::vector<std::vector<size_t>> levels

      levels[k] = node positions whose longest predecessor chain has length
      k; every node in a level is independent of the others.

      Computed with the lists above (positions are topological, so one forward pass) and
      invalidated with them.

einsums::compute_graph::SymbolicFactor

.. cpp:namespace:: einsums::compute_graph

.. cpp:class:: SymbolicFactor

   One variable raised to one power inside a monomial.

   The exponent is signed because the type does not forbid a reciprocal, but every polynomial this
   module builds uses positive exponents, and the scale-order rung of ``compare`` abstains when it
   meets a negative one.


   .. cpp:member:: SymbolicVar variable

      The variable being raised.


   .. cpp:member:: int exponent

      The power. Zero factors are dropped by canonicalization.

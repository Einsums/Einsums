einsums::compute_graph::svd_dd

.. cpp:function:: template <RuntimeRankTensorConcept AType> std::tuple<GeneralRuntimeTensor<typename AType::ValueType, std::allocator<typename AType::ValueType>>, GeneralRuntimeTensor<RemoveComplexT<typename AType::ValueType>, std::allocator<RemoveComplexT<typename AType::ValueType>>>, GeneralRuntimeTensor<typename AType::ValueType, std::allocator<typename AType::ValueType>>> svd_dd(const AType &A, linear_algebra::Vectors job)

   Divide-and-conquer singular value decomposition (returning): ``A = U * diag(S) * Vt``.

   Faster than ``svd`` for large matrices; uses LAPACK's ``gesdd`` driver.
   Returns ``(U, S, Vt)`` like ``svd``. ``job`` controls whether the
   singular vectors are computed (``ALL``, ``SOME``, or ``NONE``).
   Cannot be used during graph capture (returns by value); ``A`` is left
   unmodified.

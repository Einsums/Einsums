.. cpp:class:: Pipeline

   A pipeline of sequential stages with optional iterative loops.

   Pipeline models real computational workflows as a linear sequence of stages,
   where each stage is either:

   - A one-shot subgraph (e.g., setup, post-processing)
   - An iterative loop with convergence check (e.g., SCF iterations)

   Intermediate tensors shared across stages should be declared in the outer
   scope so they outlive the pipeline.

   **Example: SCF-like workflow**

   .. code-block:: text

      // Intermediates in outer scope
      auto tmp = create_zero_tensor<double>("tmp", N, N);

      cg::Pipeline pipeline("scf");

      // Stage 1: Setup
      {
          auto &setup = pipeline.add_stage("setup");
          cg::CaptureGuard guard(setup);
          cg::einsum(...);  // Initialize
      }

      // Stage 2: Iterative loop
      {
          auto &loop = pipeline.add_loop("scf_iter", 200,
              [&](size_t iter) { return !converged(); });
          cg::CaptureGuard guard(loop);
          cg::einsum(...);  // SCF step
      }

      // Stage 3: Post-processing
      {
          auto &post = pipeline.add_stage("post");
          cg::CaptureGuard guard(post);
          cg::einsum(...);  // Final computation
      }

      // Optimize and run
      cg::passes::ScaleAbsorption fuse;
      pipeline.apply(pm);
      pipeline.execute();

   .. cpp:function:: Graph & add_stage(const std::string &name)

      Add a one-shot (non-looping) stage to the pipeline.

      Returns a reference to the stage's Graph for use with CaptureGuard.
      Stages execute in the order they are added.

      The reference stays valid for the life of the pipeline, including across
      later add_stage() and add_loop() calls, so a caller may hold several at
      once and revisit an earlier stage.

      :param name: Human-readable name for the stage.
      :returns: Reference to the stage's Graph.


   .. cpp:function:: Graph & add_loop(std::string name, size_t max_iterations, LoopCondition condition)

      Add an iterative loop stage to the pipeline.

      Returns a reference to the loop body's Graph for use with CaptureGuard.
      The loop executes the body repeatedly until the condition returns false
      or max_iterations is reached.

      :param name: Human-readable name for the loop stage.
      :param max_iterations: Maximum number of iterations (safety limit).
      :param condition: Predicate called after each iteration. Return false to stop.
      :returns: Reference to the loop body's Graph.


   .. cpp:function:: template <typename BodyFn> void add_stage(const std::string &name, BodyFn &&body_fn)

      Add a one-shot stage with lambda-captured body.

      .. code-block:: text

         pipeline.add_stage("setup", [&]() {
             cg::einsum("ij <- ik ; kj", &C, A, B);
             cg::scale(2.0, &C);
         });

      :param name: Stage name.
      :param body_fn: Lambda capturing the stage's operations.


   .. cpp:function:: template <typename BodyFn> void add_loop(std::string name, size_t max_iterations, LoopCondition condition, BodyFn &&body_fn)

      Add a loop stage with lambda-captured body.

      .. code-block:: text

         pipeline.add_loop("scf_iter", 200,
             [&](size_t iter) { return delta > 1e-8; },
             [&]() { cg::einsum(...); cg::scale(...); }
         );

      :param name: Stage name.
      :param max_iterations: Maximum iterations (safety limit).
      :param condition: After each iteration: true → continue, false → stop.
      :param body_fn: Lambda capturing the loop body operations.


   .. cpp:function:: bool apply(PassManager &pm)

      Apply a PassManager to all stages.

      Runs all passes on each one-shot stage's Graph and each loop stage's
      body Graph. Returns true if any stage was modified.

      .. code-block:: text

         auto pm = cg::PassManager::create_default();
         pipeline.apply(pm);


   .. cpp:function:: void execute()

      Execute all stages in order.

      One-shot stages execute once. Loop stages repeat until their condition
      returns false or max_iterations is reached.


   .. cpp:function:: void execute(Executor &executor)

      Execute all stages using a custom executor.

      :param executor: The execution backend for each stage's graph.


   .. cpp:function:: void run()

      Build + run: apply default passes, materialize the associated workspace, and execute in one call.

      Convenience wrapper over
      ``apply(PassManager::create_default()) + workspace()->materialize_all() + execute()``.
      Throws if ``workspace()`` is null, pipelines must own their
      storage scope explicitly.

      .. code-block:: text

         cg::Pipeline p("compute");
         p.set_workspace(ws);
         p.add_stage("multiply", [&] { cg::einsum(...); });
         p.run();  // defaults-apply + materialize + execute


   .. cpp:function:: void run(PassManager &pm)

      Same as ``run()`` but with a caller-supplied pass manager.

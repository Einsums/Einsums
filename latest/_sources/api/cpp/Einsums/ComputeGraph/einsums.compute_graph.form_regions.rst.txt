.. cpp:function:: std::vector<Region> form_regions(const Graph &graph, const EscapeAnalysis &escapes, const RegionOptions &options)

   Find every region of ``graph``, deterministically.

   Runs are found by scanning nodes in program order, so the region set is the
   same on every run over the same graph. A region set that varied between runs
   would make every downstream rewrite vary with it.

   :param graph: The graph to scan. Sub-graphs are not descended into.
   :param escapes: The analysis over ``graph``, used to classify each region's tensors.
   :param options: Size gate; see ``RegionOptions``.
   :returns: The regions, in program order.

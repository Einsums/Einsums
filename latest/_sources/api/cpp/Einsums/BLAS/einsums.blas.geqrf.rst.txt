einsums::blas::geqrf

.. cpp:function:: template <typename T> int_t geqrf(int_t m, int_t n, T *a, int_t lda, T *tau)

   Set up for computing the QR decomposition of a matrix.

   .. math::

      \mathbf{A} = \mathbf{QR}

   Here, :math:`\mathbf{Q}` is an orthogonal matrix and :math:`\mathbf{R}` is an upper triangular matrix.

   .. versionadded:: 1.0.0

   :tparam T: The type this function handles.
   :param m: The number of rows in the input matrix.
   :param n: The number of columns in the input matrix.
   :param a: The input matrix. On exit, contains the data needed to compute the Q and R matrices. The entries on and above the diagonal are the entries of the R matrix. The rest is needed to find the Q matrix.
   :param lda: The leading dimension of the input matrix.
   :param tau: On exit, holds the Householder reflector parameters for computing the Q matrix.
   :returns: 0 on success. If negative, one of the inputs had a bad value, and the absolute value of the return tells you which one it was.

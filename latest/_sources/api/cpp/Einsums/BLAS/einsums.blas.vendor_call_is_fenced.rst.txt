einsums::blas::vendor_call_is_fenced

.. cpp:namespace:: einsums::blas

.. cpp:function:: bool vendor_call_is_fenced()

   Whether a vendor call made from this thread right now would be clamped to one thread.

   The wrappers' fence condition, for kernels choosing between the vendor (one thread when fenced)
   and their own loops (the full width). Per call; never cache it with a contraction.

   .. versionadded:: 2.0.0

.. cpp:function:: template <typename T> int_t getri(int_t n, T *a, int_t lda, const int_t *ipiv)

   Computes the inverse of a matrix using the LU factorization computed
   by getrf.

   .. versionadded:: 1.0.0

   :tparam T: The type this function handles.
   :param n: The number of rows and columns of the matrix.
   :param a: The input matrix after being processed by getrf.
   :param lda: The leading dimension of the matrix.
   :param ipiv: The pivots from getrf.
   :returns: 0 on success. If positive, the matrix is singular and an inverse could not be computed. If negative, one of the inputs is invalid, and the absolute value indicates which input is bad.

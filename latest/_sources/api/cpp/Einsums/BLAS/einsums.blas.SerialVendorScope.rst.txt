einsums::blas::SerialVendorScope

.. cpp:namespace:: einsums::blas

.. cpp:class:: SerialVendorScope

   Present ONE thread to the vendor, and to anything einsums forks from the OpenMP ICV, for as long as it exists.

   Makes reductions deterministic (a threaded ``dot's`` last bits depend on its thread count) and
   speeds small level-1 calls, where a fork costs more than the arithmetic. Width one is always safe
   to present (see ``set_moldable_width_scope``). Calling thread only; nests; restores on destruction.

   .. versionadded:: 2.0.0

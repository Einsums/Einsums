einsums::blas::iamax

.. cpp:namespace:: einsums::blas

.. cpp:function:: template <typename T> int_t iamax(int_t n, const T *x, int_t incx)

   Index of the element with the largest absolute value.

   For real vectors this locates :math:`\max_i |x_i|` (the :math:`\infty`-norm's
   argmax). For complex vectors BLAS convention applies: the maximum of
   :math:`|\mathrm{Re}(x_i)| + |\mathrm{Im}(x_i)|`, which is NOT the true
   complex modulus.

   .. note::

      Unlike the Fortran BLAS routine, this wrapper returns a 0-BASED index.

   :param n: Number of elements.
   :param x: The vector.
   :param incx: Stride between elements of x.
   :returns: Zero-based index of the first element attaining the maximum.

   .. versionadded:: 2.0.0

   :tparam T: The type this function handles.
   :param n: The number of elements to copy.
   :param x: The input vector.
   :param inc_x: The skip value for the input vector. If negative, the vector is traversed backwards. If zero, the values are broadcast to the output vector.
   :param y: The output vector.

===================
einsums::blas::gerc
===================

.. note::

Defined in header ``Einsums/BLAS.hpp``.

.. cpp:namespace:: einsums::blas

.. cpp:function:: template <typename T> void gerc(int_t m, int_t n, T alpha, const T *x, int_t inc_x, const T *y, int_t inc_y, T *a, int_t lda)

   Performs a rank-1 update of a general matrix.

   The ?gerc routines perform a matrix-vector operator defined as

   .. math::

      \mathbf{A} := \alpha\mathbf{x}\mathbf{y}^H + \mathbf{A}

   .. versionadded:: 2.0.0

   :tparam T: The type this function handle.
   :param m: The number of entries in ``x``.
   :param n: The number of entries in ``y``.
   :param alpha: The scale factor for the outer product.
   :param x: The left input vector.
   :param inc_x: The skip value for the left input. May be negative to go in reverse.
   :param y: The right input vector.
   :param inc_y: The skip value for the right input. May be negative to go in reverse.
   :param a: The output matrix.
   :param lda: The leading dimension of ``a``.
   :throws std::domain_error: If either of the dimension parameters are negative or the leading dimension of the matrix is less than the number of columns.
   :throws std::invalid_argument: If either of the vector increments are zero.

einsums::blas::threads_with_openmp
==================================

.. note::
   Generated from the C++ headers by ``apiary --emit-cpp-docs-json``.

Defined in header ``Einsums/BLAS/ThreadControl.hpp``.

.. cpp:namespace:: einsums::blas

.. cpp:function:: bool threads_with_openmp()

   Whether the linked BLAS threads through our own OpenMP runtime.

   True when ``omp_set_num_threads`` governs this thread's BLAS calls: an OpenMP-built OpenBLAS,
   asked of the library at first call since the pthread build has the same name and symbols. If
   this and ``has_per_thread_control`` are both false, the vendor's threading is ungovernable.

   .. versionadded:: 2.0.0

einsums::print::ordinal

.. cpp:namespace:: einsums::print

.. cpp:class:: template <std::integral IntType> ordinal

   Wraps an integer that prints with its ordinal suffix (1st, 2nd, ...), negatives included:

   .. code-block:: text

      fmt::format("Error with the {} argument", print::ordinal{arg_num});

   It supports in-place arithmetic like the integer it wraps, and has a ``_th`` literal suffix:

   .. code-block:: text

      fmt::format("Error with the {} argument", 3_th);

   .. versionadded:: 1.0.0

   .. versionchanged:: 2.0.0

      Added the literal suffix operator.

   :tparam IntType: The integer type the ordinal will wrap.

.. cpp:namespace:: einsums::json

.. cpp:function:: void collect_unconsumed(const Value &value, const std::string &path, std::vector<std::string> &out)

   Collect the paths of every key no reader consumed.

   Recurses into arrays and objects, so one call over the root reports the whole
   document. A path looks like ``$.nodes[3].descriptor.alpha``.

   .. versionadded:: 2.0.0

   :param value: The document, after a reader has walked it.
   :param path: Prefix for the reported paths, e.g. ``"$"``.
   :param out: Destination; paths are appended in document order.

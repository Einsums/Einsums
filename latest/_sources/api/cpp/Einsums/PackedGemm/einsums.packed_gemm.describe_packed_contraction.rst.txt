.. cpp:function:: PackedContractionShape describe_packed_contraction(const ContractionKey &key)

   What the packed engine would do with the contraction ``key`` describes.

   ``key`` carries the spec, the three operands' strides in elements and the target and link
   extents, as ``try_packed_gemm`` builds it; ``key.spec.scalar_type`` picks the micro-kernel.


.. cpp:function:: PackedContractionShape describe_packed_contraction(const OperandLayout &C, const OperandLayout &A, const OperandLayout &B, ScalarType type)

   What the packed engine would do with C = A B on operands laid out as ``C``, ``A`` and ``B``, of element type ``type``.

   Builds the key ``try_packed_gemm`` would build from tensors of these layouts. Invalid when a
   layout's three vectors disagree in length, or when the engine has no plan.

.. cpp:namespace:: einsums::packed_gemm

.. cpp:function:: template <typename T> T & bind_thread_local(T &slot)

   Returns ``slot`` through a value the compiler cannot recompute, so it keeps one address in a
   register or on the stack instead of re-deriving it from the TLS block. See "Thread-local
   buffers" above.

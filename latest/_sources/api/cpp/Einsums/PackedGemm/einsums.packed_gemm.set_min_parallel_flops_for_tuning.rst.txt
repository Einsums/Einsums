.. cpp:function:: void set_min_parallel_flops_for_tuning(int64_t flops)

   Replace ``min_parallel_flops`` while measuring the break-even it is derived from.

   Only for ``einsums-tune``. Not a setting: a program pins the threshold with
   ``--einsums:hardware:omp-min-parallel-flops``.

   .. versionadded:: 2.0.0

   :param flops: The threshold, or a negative value to return to the configured one.

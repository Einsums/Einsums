.. cpp:enum-class:: KernelRoute

   Which kernel a contraction is to be run through.

   One vendor GEMM or the packed tile loops. They differ in the last bit on some shapes, and the
   adaptive choice follows the thread regime (``einsums::blas::vendor_call_is_fenced``), so a caller
   that re-plans widths pins the route to keep results bit-stable.

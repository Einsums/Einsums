|cmake| options
===============

When configuring |einsums|, you can set a variety of options to allow CMake to
generate your specific makefiles/project files. This section includes the comprehensive list of |cmake| options.

.. _configure:

Variables that influence how |einsums| is built
------------------------------------------------

The options are split into these categories:

* :ref:`Generic options <Generic>`
* :ref:`Build Targets options <Build_Targets>`
* :ref:`Profiling options <Profiling>`
* :ref:`Debugging options <Debugging>`

.. option:: BUILD_SHARED_LIBS:BOOL

   Build using shared libraries (default: ON)

.. option:: EINSUMS_INSTALL_PYMODDIR:STRING

   Location within CMAKE_INSTALL_PREFIX to which the Python module is installed. 'naive' places in CMAKE_INSTALL_LIBDIR. 'prefix' queries the Python interpreter (still w/i PREFIX). Anything else is used directly (untested) (default: naive).

.. option:: EINSUMS_PYBIND_NUM_TU:STRING

   Split every module's generated pybind TU across this many translation units, overriding the per-module PYBIND_NUM_TU. 0 (default) leaves each module's own choice alone; 1 forces a single TU. Raise it on a build whose memory allowance is tighter than a developer machine's - the generated ComputeGraph bindings peak near 7.5 GB as one TU and around 4.7 GB split eight ways.

.. option:: EINSUMS_SIMD_NATIVE_ARCH:BOOL

   Compile SIMD-using TUs with -mcpu=native / -march=native. Unlocks every SIMD feature the host CPU    supports at the cost of binary portability.

.. option:: EINSUMS_SIMD_TARGET_CPU:STRING

   Pin SIMD-using TUs to a specific CPU model, such as 'apple-m4', 'znver4' or 'sapphirerapids'. Empty    (default) defers to EINSUMS_SIMD_NATIVE_ARCH or the toolchain baseline.

.. option:: EINSUMS_WITH_BINARY_DIR:PATH

   Root directory for libraries and executables for the build. This does not affect the installed location of libraries and executables.

.. option:: EINSUMS_WITH_CCACHE:BOOL

   Route C and C++ compiles through ccache when it is installed (default: ON)

.. option:: EINSUMS_WITH_CUDA:BOOL

   Enable support for CUDA (default: OFF)

.. option:: EINSUMS_WITH_DOCS_IN_ALL:BOOL

   Build the documentation as part of the default target rather than only on request (default OFF).

.. option:: EINSUMS_WITH_DOCUMENTATION:BOOL

   Build the Einsums documentation (default OFF).

.. option:: EINSUMS_WITH_EXAMPLES:BOOL

   Build examples (default: ON)

.. option:: EINSUMS_WITH_EXPERIMENTAL:BOOL

   If true, build experimental Einsums modules (default: OFF)

.. option:: EINSUMS_WITH_FULL_RPATH:BOOL

   Build and link libraries and executables with full RPATHs (default: ON)

.. option:: EINSUMS_WITH_GPU_MOCK_DISCRETE:BOOL

   Make the mock GPU backend imitate a discrete device (no unified memory, poisoned device pointers). Testing aid; requires no GPU.

.. option:: EINSUMS_WITH_HIDDEN_VISIBILITY:BOOL

   Use -fvisibility=hidden for builds on platforms which support it (default: ON)

.. option:: EINSUMS_WITH_MPI:BOOL

   Enable MPI distributed computing (default: OFF) WIP

.. option:: EINSUMS_WITH_MPS:BOOL

   Enable Metal Performance Shaders GPU backend

.. option:: EINSUMS_WITH_SIMD_DISPATCH:BOOL

   Compile SIMD kernel TUs once per instruction-set rung (x86-64 baseline/v2/v3/v4, aarch64 sme) and    pick the best at runtime. One portable binary, full speed on newer CPUs. OFF compiles a single TU at    the toolchain baseline. Automatically treated as OFF when EINSUMS_SIMD_NATIVE_ARCH or    EINSUMS_SIMD_TARGET_CPU pins the build.

.. option:: EINSUMS_WITH_TESTS:BOOL

   Build tests (default: ON)

.. option:: EINSUMS_WITH_TESTS_BENCHMARKS:BOOL

   Build benchmark tests (default: ON)

.. option:: EINSUMS_WITH_TESTS_DLPNO_TRIPLES:BOOL

   Run the DLPNO (T0) and iterative (T) example suites, which hang or return a      wrong energy nondeterministically on some platforms (default: OFF)

.. option:: EINSUMS_WITH_TESTS_EXAMPLES:BOOL

   Add examples as tests (default: ON)

.. option:: EINSUMS_WITH_TESTS_HEADERS:BOOL

   Build header tests (default: ON)

.. option:: EINSUMS_WITH_TESTS_UNIT:BOOL

   Build unit tests (default: ON)

.. py:function:: omp_min_parallel_flops() -> int

    Work, in flops, below which parallelizing a contraction is a net loss.

    The region cost times a multiplier calibrated end to end on tiled CCSD residuals.
    ``--einsums:hardware:omp-min-parallel-flops`` pins it.


.. py:function:: omp_region_cost_ns() -> float

    Cost in nanoseconds of entering and leaving an OpenMP parallel region.

    An empty region at the current team size, warm team, best of several trials: around 20 us on
    a 10-thread machine. Read from the hardware profile (written only by ``einsums-tune``) when it
    has an entry for the current team size, otherwise measured, which drifts by tens of percent
    per process.
    ``--einsums:hardware:omp-region-cost-ns`` pins it.

    Set the OpenMP runtime's ceiling on a parallel region's team size.

    ``omp_set_num_threads()``, which also governs OpenMP-threaded BLAS; for a per-thread BLAS

    .. versionadded:: 2.0.0

    :param nthreads: Thread count ceiling to request.


.. py:function:: tune(args: list[str]) -> int

    Measure this machine and write its hardware profile, or report on the profile in effect.

    The one implementation behind the ``einsums-tune`` executable, ``einsums`` ``tune`` and
    ``python`` ``-m`` ``einsums.tune``. Without an action it measures GEMM efficiency, memory and
    cache bandwidth, permute throughput, call overhead, per-kernel thread efficiency and the OpenMP
    region cost, and writes them as one profile, by default this machine's in the cache directory.
    The actions report instead: ``--show`` the profile in effect and why one is not used, ``--check``
    whether a current one applies, ``--export`` its path, and ``--import`` adopts a file measured
    elsewhere. ``--help`` lists every argument.

    The runtime must be running; its own ``--einsums:*`` options among ``args`` are skipped.

    .. versionadded:: 2.0.0

    :param args: The arguments, without the program name.
    :returns: The exit status: 0 on success, 1 when an action reports failure, 2 for bad arguments.

void permute(U const UC_prefactor, std::tuple<CIndices...> const &C_indices, CType *C, U const UA_prefactor, std::tuple<AIndices...> const &A_indices, AType const &A)#

Permutes the elements of a tensor and puts it into an output tensor.

This function uses HPTT, which can only handle out-of-place tensor transpositions. The tensors passed in should not have overlapping storage.

Parameters:

  • UC_prefactor – The prefactor for mixing the output tensor.

  • C_indices – The indices for the output tensor.

  • C – The output tensor.

  • UA_prefactor – The prefactor for the input tensor.

  • A_indices – The indices for the input tensor.

  • A – The input tensor.

Template Parameters:

ConjA – If true, conjugate the values of A as it is being permuted.

  • A_indices – The indices for the input.

  • A – The input tensor.

  • method – Indicates which method HPTT should use to optimize the permutation. By default, it is hptt::ESTIMATE , which is the simplest of the options.
